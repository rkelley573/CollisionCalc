# Collision Investigation Assistant

**Developed by Richard Kelley**

A professional tool designed to aid law enforcement collision investigators 
by centralizing case information, automating calculations, and streamlining 
the investigative workflow from scene to report.

## What It Does

- Keeps investigation data organized and accessible in one place
- Computes collision-related calculations automatically, reducing manual error
- Streamlines the investigative process to reduce time spent per case
- Generates exportable reports that document the investigator's methodology 
  and work — creating a clear, defensible record suitable for evidentiary 
  submission and court proceedings

## Who It's For

Built specifically for collision investigators and traffic enforcement 
professionals who need accurate, well-documented, and court-ready case records.
